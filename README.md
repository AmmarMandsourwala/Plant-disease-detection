## 🔍 How It Works

1. 📥 Upload an image of a plant leaf  
2. 🧠 The model analyzes the image using a trained CNN  
3. 📊 Get the prediction – whether it's healthy or diseased  
4. ✅ Simple, fast, and easy to use!

---

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/AmmarMandsourwala/plant-disease-detection.git
cd plant-disease-detection

# 2. Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Install the dependencies
pip install -r requirements.txt

# 4. Run the app
python app.py

# Visit http://127.0.0.1:5000 in your browser
```

---

## 🧠 Model Info

- CNN-based image classifier  
- Trained on [PlantVillage dataset](https://www.kaggle.com/datasets/emmarex/plantdisease)  
- Supports multiple crops & disease types  
- Achieved ~95% accuracy on validation data
